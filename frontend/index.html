CrowdTwin AI

Predictive Crowd Digital Twin for Dynamic Stadium Crowd Routing and Evacuation

A closed-loop system that turns live simulated crowd state into machine-learning forecasts, dynamic graph costs, optimized routes, operator decisions, and an updated 3D twin.

Research problem

Beyond static paths

Distance-only evacuation routes ignore queues, capacity pressure, closures, and emerging bottlenecks.

Beyond reaction

Reactive routing sees congestion after it forms. CrowdTwin tests whether near-term density forecasts produce different route choices.

Reproducible what-if tests

Isolated scenario copies test crowd increases, closures, and emergencies without mutating the operational twin.

Closed-loop research pipeline

Crowd Data→Digital Twin→Current State→ML Prediction→Future State→Dynamic Graph→Dijkstra / A*→Route→What-If→Decision→Updated Twin

Data structures

Arrays and 2D occupancy grids hold density. Linked lists track movement. Queues model service, circular queues sample checkpoints, stacks retain state, heaps rank congestion, hash tables locate zones, AVL/BST structures order records, and graphs encode movement.

Artificial intelligence

A Random Forest baseline trains on the included documented synthetic seed series. It uses density, recent flow, capacity, queue, and time features for +1, +3, and +5 minute horizons. MAE, RMSE, and R² are calculated from held-out rows.

Digital twin

The virtual stadium mirrors population, density, gates, corridors, checkpoints, exits, blocks, predictions, and calculated routes. Every dynamic display is supplied by the FastAPI backend.

Scope: This is a research and teaching prototype. It is not a certified crowd-safety or evacuation-planning system.
